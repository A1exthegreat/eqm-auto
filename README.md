# 中科大教学评价自动完成

> Tampermonkey 用户脚本 — 自动完成 tqm.ustc.edu.cn 的期末教学评价

## 功能

- 自动填写所有单选题（每组 radio 选第一项）
- 自动填写所有多选题（每组 checkbox 勾选第一项）
- 自动清空问答题
- 自动提交评价
- 自动处理多位教师/助教 tab（只评价第一位，其余忽略）
- 自动切换到下一课程，直至全部完成
- 浮动控制按钮，运行中可随时停止

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/) 扩展
2. **推荐**：直接访问 [tqm-auto-eval.user.js](https://raw.githubusercontent.com/A1exthegreat/eqm-auto/main/tqm-auto-eval.user.js)，脚本管理器会自动弹出安装页面
   - 通过 URL 安装后，脚本管理器会自动从 GitHub 检查并提示更新
   - 若 `raw.githubusercontent.com` 无法访问，可改用 jsDelivr 镜像：[tqm-auto-eval.user.js (jsDelivr)](https://cdn.jsdelivr.net/gh/A1exthegreat/eqm-auto@main/tqm-auto-eval.user.js)
3. 也可复制全部代码，在 Tampermonkey 中新建脚本粘贴保存（此方式无法自动更新）

## 使用

1. 登录 [tqm.ustc.edu.cn](https://tqm.ustc.edu.cn)
2. 进入「我的任务」→ 点击任意一个「评价」进入评价页面
3. 页面右下角出现蓝色浮动按钮「**开始评价**」
4. 点击按钮，脚本自动运行
5. 运行中按钮变为红色「**停止中…**」，再次点击可停止
6. 全部完成后按钮恢复「开始评价」

### 按钮状态

| 状态 | 颜色 | 含义 |
|------|------|------|
| 空闲 | 蓝 | 可点击开始评价 |
| 运行中 | 红 | 正在自动处理 |
| 停止中 | 灰（不可点） | 正在等待当前操作收尾 |
| 停止后 | 蓝 | 已停止，可再次开始 |

## 运行流程

```
点击「开始评价」
  └─ 进入课程循环（最多 20 门课）
       ├─ 等待问卷渲染
       ├─ 获取教师/助教 tab 列表
       ├─ 评价第一位教师
       │    ├─ 切换 tab
       │    ├─ 填写所有单选题
       │    ├─ 填写所有多选题
       │    ├─ 清空问答题
       │    └─ 点击「提交」
       ├─ 忽略其余教师（每人点击「忽略问卷」）
       ├─ 评价第一位助教（同上流程）
       ├─ 忽略其余助教
       └─ 点击「下一课程」
            └─ 若按钮不可用 → 全部完成
```

## 配置

脚本开头的 `DELAY` 对象包含所有时间参数（单位毫秒）：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `CLICK` | 500 | 点击后的短暂等待 |
| `TAB_SWITCH` | 800 | 切换 tab 后等待渲染 |
| `SUBMIT_WAIT` | 1500 | 提交后等待后端处理 |
| `IGNORE_WAIT` | 800 | 点击忽略后等待处理 |
| `NEXT_COURSE` | 2500 | 切换课程后等待新页面加载 |
| `POLL_INTERVAL` | 200 | 轮询间隔 |
| `POLL_TIMEOUT` | 8000 | 轮询超时上限 |

如需调整，直接修改脚本顶部 `DELAY` 对象的数值。

页面底部的 `MAX_COURSES = 20` 限制最大处理课程数，如需修改在 `run()` 函数中调整。

## 注意事项

### 安全声明

- 脚本 **不会** 向任何第三方发送数据
- 脚本 **不会** 读写 Cookie、localStorage 或发起任何网络请求
- 脚本 **不会** 修改页面中用户已手动填写的问答题内容
- 脚本以 `@grant none` 运行，拥有页面完整 DOM 访问权限，但功能仅限于自动填写和提交评价

### 已知限制

- 硬编码单选/多选题默认选中第一项，不反映真实评价意愿
- 固定延迟时间在网络较慢时可能不够用
- `MAX_COURSES = 20` 硬上限，超出部分不会被处理
- 停止按钮响应粒度限于每个 tab 操作之间，不会立即中断正在执行的点击或网络请求

### 学术诚信

该脚本用于自动化教学评价流程。使用前请确认所在学校/院系的相关规定。自动化评价会使收集到的反馈数据失去参考价值，影响教学质量改进工作的有效性。
